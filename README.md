Entry for the [make.fun](https://make.fun) competition
**Ridiculous at First Glance, Real by the Second** — one sentence, at most
200 characters, pitching a bizarre startup idea that sounds absurd until
you realise it would actually sell.

## The pitch

> We turn idle backyard pools into trout farms, paying homeowners rent
> while local restaurants buy the fish, because every pool already holds
> filtered water behind a fence.

(170 characters.)

The laugh: trout farming in someone's swimming pool. The nod: the pool
already has filtered water and a fence, it sits idle all winter, the
homeowner earns rent on a dead asset, and restaurants pay for local fish.

## How it works

`main.py` (Python 3.13, no dependencies, no network, no randomness)
writes the sentence above to `/output/entry.txt`. Every run writes the
exact same bytes.

```sh
python3 main.py
cat /output/entry.txt
```
